MFG Calcs provides free manufacturing calculators, live U.S. cost data, tariff information, and industry guides. Operated by a solo founder in Massachusetts, the site offers over 5,000 calculators across 241 categories, with formulas, inputs, and sources displayed openly. No signup or API key is required, and the platform also exposes a keyless JSON API for programmatic access to calculators, data, tariffs, and forecasts.

**Areas:** Manufacturing · Calculators · Data · Free · API
